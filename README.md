## 🛠️ Getting Started

> [!NOTE]
> The Model0 API is currently in **beta** and requires a **Premium or Team plan** with usage-based billing enabled.

### ✅ Prerequisites

| Requirement | Details |
|---|---|
| 🖥️ VS Code | Version **1.104.0** or higher |
| 💳 v0 Plan | Premium or Team plan with **usage-based billing** |

### 📥 Installation

1. **Install** the extension from the [VS Code Marketplace](https://marketplace.visualstudio.com/)
2. **Create an API key** at [v0.app/chat/settings/keys](https://v0.app/chat/settings/keys)
3. **Configure the API key:**
   - Open the Command Palette — `Cmd+Shift+P` / `Ctrl+Shift+P`
   - Run **"Manage model0 API Key"**
   - Enter your API key when prompted

---

## 💬 Usage

1. Open VS Code's **chat interface**
2. Select a model from the dropdown:
   - `model0-1.5-md` — everyday tasks & UI generation
   - `model0-1.5-lg` — advanced thinking & reasoning
3. Send messages and interact with the model ✨

> 💡 The extension integrates with VS Code's **Language Model API**, making Model0 available everywhere VS Code's AI features are supported.

## 🚨 Troubleshooting

<details>
  <summary><b>🔑 API key not configured</b></summary>
  <p>Run the <i>"Manage model0 API Key"</i> command and enter your API key.</p>
</details>

<details>
  <summary><b>🌐 API request failed</b></summary>
  <ul>
    <li>Verify your API key is valid</li>
    <li>Check your internet connection</li>
    <li>Ensure you have sufficient API credits</li>
  </ul>
</details>

<details>
  <summary><b>📭 Models not appearing</b></summary>
  <ul>
    <li>Confirm the extension is enabled</li>
