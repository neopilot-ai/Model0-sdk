## [0.1.0-preview.0] - 2026-07-31

### Added

- `model0-1.5-md` and `model0-1.5-lg` language models in VS Code chat
- OpenAI-compatible chat completions with streaming responses
- Multimodal support for text and image inputs
- Function/tool call support
- "Manage model0 API Key" command with secure secret storage
- Extension marketplace package (VSIX)
